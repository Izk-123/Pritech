# 🏢 Core App — Complete System Design

The **Core App** is the central foundation of the Pritech System. It contains shared functionality, system-wide configurations, dashboards, navigation, branding, settings, and reusable components used by all other apps.

Think of it as the **control center** that connects:

```text
Accounts
Clients
Services
Tickets
Finance
Portfolio
Tracking
AI Engine
Notifications
```

---

# 🎯 Purpose

The Core App is responsible for:

* Main Dashboard
* System Settings
* Site Configuration
* Company Branding
* Navigation/Menu Management
* Announcements
* Dashboard Widgets
* System Preferences
* Global Search

* Shared Utilities

# ⚙️ How Dashboard Works

Instead of:

```text
finance/dashboard/
ticket/dashboard/
client/dashboard/
```

Use:

```text
dashboard/
```

The system loads widgets according to user roles.

Example:

```python
if user.is_finance:
    show_finance_widgets()

if user.is_technician:
    show_ticket_widgets()
```

# 🎯 Main Goal of the Core App

> **To provide a centralized control center that manages system-wide settings, branding, dashboards, navigation, notifications, monitoring, and shared functionality while delivering a personalized real-time experience for every user of the Pritech System.**

## Position Within Pritech ERP Architecture

```text
                    Core App
                        │
 ┌──────────────┬──────────────┬──────────────┐
 │              │              │
Accounts      Clients       Portfolio
 │              │              │
Services      Tickets       Finance
 │              │              │
Tracking    Notifications   AI Engine
```

The **Core App is the brain of the system**, coordinating all modules and providing the single entry point (dashboard) through which users interact with the entire Pritech ERP platform. 🚀🏢📊🔐
