# 🛠️ Service Management Module

The **Service Management Module** is one of the most important modules in the Pritech System because it defines, manages, delivers, monitors, and analyzes all ICT services offered by Pritech.

---

# 🎯 Purpose

The Service Management Module enables Pritech to:

* Define services offered to clients
* Manage service packages
* Monitor service delivery
* Connect services to tickets
* Connect services to quotations and invoices
* Track service performance
* Analyze service profitability
* Improve customer satisfaction

# 🗄️ Database Design

---

## ServiceCategory

```python
class ServiceCategory(models.Model):
    name
    description
    icon
    is_active
```

Examples:

* Networking
* ICT Support
* Web Development
* Security Systems

---

## Service

```python
class Service(models.Model):
    category
    name
    code
    description

    billing_type
    base_price

    estimated_hours

    is_active

    created_at
```

---

## ServicePackage

```python
class ServicePackage(models.Model):
    name
    description

    services

    package_price

    is_active
```

Example:

### SME Package

Includes:

* Network Maintenance
* Website Hosting
* ICT Support

---

## ClientService

Tracks services purchased by clients.

```python
class ClientService(models.Model):
    client
    service

    start_date
    end_date

    status
```

---

## ServiceRequest

Represents client demand for a service.

```python
class ServiceRequest(models.Model):
    client

    service

    description

    status

    created_at
```

---

## ServiceAssignment

Tracks technician assignments.

```python
class ServiceAssignment(models.Model):
    service_request

    technician

    assigned_at

    completed_at
```
